## 🌟 Welcome!

Hey there! 👋 Welcome to my machine learning playground! This repository contains computer vision and machine learning experiments, focusing on real-time object detection and recognition using classical ML techniques.

## 🎯 What's Inside?

### 🤖 Computer Vision Projects
- **[hog-svm-object-detection](hog-svm-object-detection/)** 🎯 - Real-time object detection using HOG features and SVM classification

## 🛠️ Tech Stack

- **Language**: Python 3.8+
- **Computer Vision**: OpenCV 4.x
- **Machine Learning**: scikit-learn
- **Feature Extraction**: HOG (Histogram of Oriented Gradients)
- **Classification**: SVM (Support Vector Machine)
- **Utilities**: numpy, joblib

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/AliesterEroan/machine-learning.git
   ```

2. **Install dependencies**
   ```bash
   cd machine-learning/hog-svm-object-detection
   pip install -r requirement.txt
   ```

3. **Run a project**
   - Check individual project README for specific instructions
   - Prepare your dataset
   - Train the model
   - Run real-time recognition

## 📱 Project Highlights

### 🎯 HOG + SVM Object Detection
Complete real-time object recognition system:
- HOG feature extraction for robust object representation
- SVM classification for accurate recognition
- Motion detection using background subtraction
- Real-time webcam processing
- Visual feedback with bounding boxes and confidence scores
